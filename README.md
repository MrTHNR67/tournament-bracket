# بطولة المواجهات 🏆

تطبيق ويب عربي بملف واحد لتنظيم بطولة خروج مغلوب بالأصوات: تدخل الأسماء، تخلطها عشوائياً، ثم تسجّل أصوات الجمهور في كل مواجهة. الأعلى أصواتاً يتأهل، وتستمر الجولات إلى أن يبقى بطل واحد.

## المميزات

- إدخال من 2 إلى 128 اسماً، بتوزيع ومواجهات عشوائية.
- تأهلات تلقائية عندما يكون العدد فردياً (مثال: 21 اسماً = 5 مواجهات + 11 تأهلاً).
- تسجيل أصوات كل اسم في كل مواجهة، ومنع التعادل.
- انتقال تلقائي بين الجولات: دور 16، ربع النهائي، نصف النهائي، النهائي.
- سجل نتائج الجولات السابقة وشاشة تتويج البطل.
- حفظ تلقائي للتقدم في المتصفح.
- واجهة عربية RTL متجاوبة مع الجوال، بدون أي اعتماديات.

## التشغيل محلياً

افتح `tournament.html` مباشرة في أي متصفح حديث، أو شغّل خادماً محلياً:

```bash
npx serve .
```

## النشر على Render

المستودع مجهّز للنشر كموقع ثابت عبر `render.yaml`. استخدم زر النشر التالي:

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/MrTHNR67/tournament-bracket)

بعد تسجيل الدخول إلى Render وربط GitHub:

1. اختر اسم الخدمة (أو اتركه `tournament-bracket-mrthnr`).
2. اضغط **Apply** ثم انتظر انتهاء النشر.
3. ستحصل على رابط عام مثل `https://tournament-bracket-mrthnr.onrender.com` جاهز للمشاركة.

## البنية

| الملف | الوظيفة |
|---|---|
| `tournament.html` | التطبيق كاملاً (HTML + CSS + JavaScript) |
| `index.html` | تحويل الجذر إلى صفحة التطبيق |
| `render.yaml` | إعدادات النشر كموقع ثابت على Render |
