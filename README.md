# بطولة المواجهات 🏆

تطبيق ويب عربي لبطولة خروج مغلوب (جولات): أدخل الأسماء، شارك الرابط، ويصوّت الجميع من أجهزتهم في كل مواجهة. الفائز يكمل للجولة التالية حتى يبقى بطل واحد. النتائج تتحدث مباشرة.

**النسخة المباشرة:** https://mrthnr67.github.io/tournament-bracket/

## المميزات

- بطولة خروج مغلوب (جولات) مع تصويت من عدة أجهزة.
- من 2 إلى 128 اسمًا، بتوزيع عشوائي (تأهلات تلقائية للأعداد الفردية).
- صوت واحد لكل مصوّت في كل مواجهة (جلسة مجهولة، بدون إيميل).
- إغلاق/إعادة فتح المواجهات، وتحديد الفائز (للتعادل)، والانتقال للجولة التالية.
- شاشة تتويج البطل، وقائمة المشاركين with حالة الإقصاء.
- نتائج مباشرة تتحدث تلقائيًا.
- واجهة عربية RTL متجاوبة مع الجوال.
- صفحة تصويت بسيط (خيار واحد/عدة) متاحة على `poll.html`.

## وضع الإدارة

1. افتح الموقع واضغط «وضع الإدارة».
2. أدخل رمز الإدارة (الافتراضي: `admin` — غيّره في `tournament_data.settings`).
3. أدخل الأسماء (اسم في كل سطر) واضغط «بدء بطولة جديدة».
4. شارك الرابط مع الجميع.
5. في كل مواجهة: اضغط «فوز …» لإغلاقها وتحديد الفائز (أو «إعادة فتح التصويت» للتعادل).
6. بعد إغلاق جميع مواجهات الجولة، اضغط «الانتقال للجولة التالية».
7. عند بقاء بطل واحد، تظهر شاشة التتويج.

## إعداد Supabase

- **Project URL:** `https://tgrrpgrnctgpgjftlnti.supabase.co`
- **Publishable Key:** موجود داخل `index.html` (مفتاح عام آمن للواجهة).
- **Anonymous Sign-Ins:** مفعّل.
- **المخطط الكامل:** `tournament.sql` (البطولة) و `supabase.sql` (التصويت البسيط).

### تغيير رمز الإدارة

```sql
update tournament_data.settings set admin_token = 'رمز-جديد' where singleton;
```

### تصفير البطولة لبدء بطولة جديدة

من «وضع الإدارة» أدخل الأسماء واضغط «بدء بطولة جديدة»، أو من SQL:

```sql
select public.admin_reset_tournament('admin', array['اسم1','اسم2','اسم3']);
```

### عرض حالة البطولة

```sql
select public.get_tournament_state();
```
